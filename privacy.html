개인정보처리방침

시행일: 2026-09-28 (방문 통계 항목 추가) · 대상: seasonalfood (유튜브 채널 "오늘의 제철 음식!" 운영자용 업로드 도구)

1. 사용자

이 도구는 채널 운영자 1인만 사용합니다. 일반 사용자에게 제공되지 않습니다.

2. 사용하는 Google 데이터

  • youtube.upload: 운영자가 만든 영상을 운영자 본인 채널에 업로드
  • youtube.readonly: 로그인한 계정의 채널 이름·ID 확인

다른 사람의 계정, 영상, 댓글, 연락처 등은 읽거나 저장하지 않습니다.

3. 저장

OAuth 토큰과 업로드한 영상 ID는 운영자의 개인 컴퓨터에만 저장됩니다. 외부 서버로 전송하거나 제3자와 공유·판매하지 않습니다.

4. 삭제

운영자는 언제든 로컬 토큰 파일을 지우거나 Google 계정 › 서드파티 연결에서 접근 권한을 해제할 수 있습니다.

5. Google API 서비스 정책

이 도구의 Google API 데이터 사용은 Google API Services User Data Policy와 YouTube API Services Terms of Service를 따릅니다. 유튜브 서비스 약관: https://www.youtube.com/t/terms, Google 개인정보처리방침: https://policies.google.com/privacy

6. 구매 링크 모음 페이지 방문 통계

구매 링크 모음 페이지는 방문 수와 '쿠팡에서 보기' 클릭 수를 세기 위해 GoatCounter를 사용합니다. 쿠키를 쓰지 않고, 이름·이메일 등 개인을 식별하는 정보를 수집하지 않습니다. 페이지 주소, 유입 경로(referrer), 브라우저·기기 종류, 국가, 화면 크기만 집계합니다.

Privacy Policy (English)

Effective 2026-09-28. seasonalfood is used only by the owner of the YouTube channel "Today's Seasonal Eats!". It uses the youtube.upload scope to upload the owner's videos to the owner's channel and youtube.readonly to confirm the signed-in channel. It does not read or store other users' data. OAuth tokens and uploaded video IDs are stored only on the owner's computer and are never sent to other servers, shared, or sold. Access can be revoked at any time at Google Account › Third-party connections. Use of Google API data complies with the Google API Services User Data Policy and the YouTube API Services Terms of Service, including the YouTube Terms of Service and Google Privacy Policy. The purchase links page uses GoatCounter to count page views and "쿠팡에서 보기" clicks. It sets no cookies and collects no personally identifying information; only page URL, referrer, browser/device type, country and screen size are aggregated. Contact: GitHub Issues
